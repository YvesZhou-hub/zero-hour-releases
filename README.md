## 怎么玩

WASD / 方向键移动，自动攻击；空格闪避，E 爆发，ESC 暂停，M 静音。设置支持中英切换、音量、画质、减少特效和按键重映射。

选择一个初始能力，收集能量升级。每局最多两系能力，两系分别达到 II 级会解锁融合。靠近已解锁的稳定锚累计充能八秒，完成三个稳定锚、击败约 2:30、5:30、8:30 登场的三只奶龙首领，并坚持至少十分钟后撤离。首领尚未击败时战斗会继续。
